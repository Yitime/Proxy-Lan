# Proxy-Lan

一款基于 SwitchyOmega / ZeroOmega 改造的浏览器代理管理工具，支持多个代理配置、自动切换和规则列表。

## 安装

从 [GitHub Releases](https://github.com/Yitime/Proxy-Lan/releases/latest) 下载扩展 ZIP 安装包并解压，然后：

1. 打开 Chrome 的 `chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择解压后的扩展目录

修改代码后，在扩展管理页面点击“重新加载”。

## 开发检查

项目不需要安装第三方依赖。需要 Node.js 18 或更高版本。

```powershell
node scripts/validate.mjs
node --test tests/options-navigation.test.mjs tests/options-io.test.mjs tests/core-runtime.test.mjs tests/error-log.test.mjs tests/options-errors.test.mjs
```

也可以使用：

```powershell
node --run check
node --run test
```

检查内容包括 JavaScript 语法、JSON、Manifest 资源、HTML 和 CSS 本地资源引用、国际化 key，以及后台消息方法白名单。

配置保存在本地，可通过 JSON 文件备份和恢复。旧版备份导入时会清理同步标记、自定义样式、快速切换、网络监控、初始模式和高级条件显示设置。虚拟模式会转换为实际目标；独立 PAC 模式、缺失或循环目标回退为直连，并更新规则引用。已移除发布规则列表功能，仍可编辑规则源代码和导入在线规则列表。

默认模式为“翻墙”和“自动”。旧版 `proxy`（或 `Proxy`）和 `auto switch` 在首次加载时改名，保留代理参数并更新规则和当前模式；已有同名中文模式时保留原配置，避免覆盖。

新安装的“翻墙”模式不再预填示例服务器，“自动”模式也不包含示例域名规则。请先在“翻墙”模式选择代理协议并填写地址、端口，再使用代理或自动分流。未配置时切换会提示前往配置，并保留当前模式。已有配置和自定义规则不会被清空。

代理地址支持域名、IPv4 和 IPv6，自动清理首尾空格；端口必须是 1–65535 的整数。输入错误会在字段旁提示，并阻止保存。

“自动”模式默认订阅 [GFWList](https://raw.githubusercontent.com/gfwlist/gfwlist/master/gfwlist.txt)，格式为 AutoProxy，命中订阅规则的请求使用“翻墙”，其他请求直连。添加规则列表时也会预填此地址与格式。已有自定义在线订阅和本地规则会保留。

临时规则及管理页面已移除，旧会话中的临时覆盖会自动清除。弹窗添加的规则直接保存到当前自动切换模式中。

设置页、代理弹窗、规则表单、权限页及对话框采用统一的蓝灰界面，自动适配系统深色模式。设置页侧栏底部显示保存状态，并提供应用修改、撤销修改和重置配置入口。

系统代理和直接连接支持自定义显示名称，编辑时侧栏即时更新，保存后同步到弹窗和规则列表。模式颜色支持预设色块、自定义 HEX 颜色和透明度。代理弹窗宽度为 160px，已移除品牌图标、标题、当前配置卡片、当前页面栏和自定义快捷键。

工具栏图标在手动模式下只显示该模式颜色的外圈，中心透明；自动分流时，外圈显示最终匹配的模式颜色，透明中心显示同色字母“A”，表示自动模式。

规则更新间隔位于“规则列表设置”，统一作用于所有在线规则列表；“重置选项”位于侧栏操作区。启动时沿用上次模式，已有高级条件规则会自动显示相应编辑选项。

自动模式的订阅和独立规则列表共用一个编辑组件，默认收起在线规则原文和订阅参数，仅展示更新时间、规则数量和更新按钮。下载失败会持续显示原因并提供重试。在线规则原文只读；清空订阅地址后可编辑本地规则。单条规则的复制和备注位于“更多”菜单，批量操作和统一修改目标的箭头已移除，保留拖动排序。

独立 PAC 模式及脚本导出已移除。自动切换仍通过内部生成的 PAC 脚本设置 Chromium 代理。

## 主要目录

- `manifest.json`：扩展配置
- `js/background.js`：后台代理逻辑
- `popup/`：代理弹窗、权限及连接状态页面
- `options.html`、`partials/`：设置页面
- `_locales/`：界面翻译
- `lib/`：随项目打包的第三方库

## 隐私说明

配置保存在浏览器本地。问题反馈会附带最近一条错误（最多 4000 字符）；不再持久化每日完整日志。
